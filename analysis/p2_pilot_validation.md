# P2 parameter-matched pilot validation

## Overall assessment: Needs revision

The three 30-epoch seed-0 pilots are reproducible and suitable for choosing
which models merit extended training, but they do not pass the P2 scientific
gate. No result in this document supports proceeding to P3.

## Methodology review

- Population: the frozen 50/25/125 complete-case
  `legacy_case1_corrected_matched_v1` split.
- Grain: one row per complete test case; grid points are not treated as
  independent samples.
- Parameter counts: 198,802 (joint FNO2d), 198,282 (factorized FNO), and
  225,162 (causal factorized), a maximum/minimum ratio below 1.15.
- Selection: validation weighted objective only.
- Test metrics are emitted by the fixed trainer and reported descriptively.
  They must not drive the extended-run configuration.
- Every run was recomputed from saved predictions, including α bounds,
  monotonicity, and zero tool cure.

## Calculation spot checks

- P1 temperature reference: loaded from the frozen three-seed corrected field
  summary, not copied from prose.
- P1 spatial-gradient reference: independently recomputed from each saved
  `[case,position,time]` field using first differences over adjacent 1 mm
  positions, then aggregated per complete case.
- P2 gradient metric: the same first-difference definition over the canonical
  `[case,time,position]` field.
- Resumed pilot cost: `history.parquet` epoch durations are summed. The last
  session wall clock in old run metrics is not used because forced execution
  windows interrupted two pilots.

## Material issues

1. The best pilot temperature field error is still above the corrected P1
   reference.
2. The validation optima occur at or near the final pilot epoch, indicating
   undertraining rather than a converged negative result.
3. One seed is insufficient for uncertainty or statistical comparison.
4. Pilot test results have already been generated by the fixed pipeline.
   Extended configurations are therefore frozen from validation evidence only,
   and no test-driven tuning is permitted.

## Required next checks

- Extend factorized and causal training with frozen, validation-selected
  settings.
- Independently verify the resulting saved predictions.
- Re-run the P1-comparable temperature and spatial-gradient gate.
- Preserve a failed gate and stop before P3 if no joint model matches the
  corrected reference.
